## CINESCOPE

> Plataforma web para consulta, análise e recomendação de filmes.

## 📖 Sobre o projeto

O **CineScope** é um projeto acadêmico desenvolvido com o objetivo de criar uma plataforma web voltada para pessoas que gostam de filmes e desejam encontrar informações sobre diferentes obras cinematográficas.

A proposta é desenvolver uma aplicação inspirada em plataformas de informações sobre filmes, permitindo que o usuário consulte dados como título, sinopse, gênero, ano de lançamento, avaliação, elenco, diretor e outras informações relevantes.

Além da consulta, o projeto busca oferecer recursos interativos que auxiliem o usuário na escolha do que assistir, como avaliações e filtros.

O projeto será desenvolvido utilizando **HTML e CSS**.

---

## 🎯 Objetivo

O principal objetivo do CineScope é desenvolver uma plataforma simples, intuitiva e funcional para consulta e análise de filmes.

### Objetivos específicos

- Criar uma interface organizada e fácil de utilizar;
- Permitir a pesquisa de filmes;
- Exibir informações detalhadas sobre cada filme;
- Organizar filmes por diferentes categorias;
- Permitir avaliações dos usuários;
- Implementar filtros de pesquisa;
- Aplicar conhecimentos de desenvolvimento web adquiridos durante o curso.

---

## 👥 Público-alvo

O CineScope é destinado principalmente a:

- Pessoas que gostam de filmes;
- Usuários que procuram algo para assistir;
- Pessoas que desejam conhecer informações sobre um filme antes de assisti-lo;
- Usuários interessados em descobrir novos filmes;
- Pessoas que gostam de avaliar filmes.

---

## 💡 Problema

Atualmente, informações sobre filmes podem estar distribuídas em diferentes sites e plataformas.

O CineScope busca solucionar esse problema reunindo informações importantes sobre os filmes em uma única plataforma, permitindo que o usuário encontre rapidamente aquilo que procura.

---

## 🚀 Funcionalidades

O projeto contará com funcionalidades como:

### 🔎 Pesquisa de filmes

O usuário poderá pesquisar filmes pelo nome através de uma barra de pesquisa.

### 🎞️ Catálogo

Será disponibilizada uma lista de filmes contendo informações básicas, como:

- Pôster;
- Título;
- Ano;
- Gênero;
- Nota.

### 📋 Detalhes do filme

Ao selecionar um filme, o usuário poderá visualizar informações mais completas:

- Título;
- Sinopse;
- Ano de lançamento;
- Gênero;
- Duração;
- Diretor;
- Elenco;
- Avaliação;
- Trailer, quando disponível.

### 🔽 Filtros

O usuário poderá filtrar os filmes de acordo com critérios como:

- Gênero;
- Ano de lançamento;
- Avaliação.

## 🛠️ Tecnologias utilizadas

O projeto será desenvolvido utilizando tecnologias fundamentais para desenvolvimento web.

### HTML5

Utilizado para construir a estrutura das páginas e organizar os elementos da aplicação.

### CSS3

Utilizado para desenvolver a aparência da plataforma, incluindo:

- Layout;
- Cores;
- Tipografia;
- Cards;
- Responsividade;
- Animações e efeitos visuais.
